# 03 卡片：3D 盒体、倒影与"选中程度"

本文讲的算法移植自原作场景，这里解释的是本仓库对它的实现。

## 画面上是什么

一排卡片站在一条地面线上。选中的那张更大、更靠前、边缘有一圈用应用颜色描的亮边，表面有一道斜向的白色高光扫过。两侧的卡片朝中间微微偏转。每张卡片下方有一个压暗、渐隐的倒影。

这些卡片是真正的三维盒体，由透视相机看到，不是平面贴图。

## 术语

- **透视相机**：近大远小。相机在 z = 6 处看向原点，所有点沿视线收缩到屏幕上。
- **模型矩阵（model matrix）**：一个 4×4 矩阵，把盒体自己的坐标（本地坐标）变换成场景里的世界坐标。由平移、旋转、缩放相乘得到。
- **MVP 矩阵**：投影 × 视图 × 模型，一次把本地坐标变到屏幕上。
- **法线（normal）**：垂直于表面的方向，光照靠它判断表面朝不朝光。
- **预乘 alpha（premultiplied alpha）**：颜色已经乘过透明度再输出。见下文"混合与绘制顺序"。

## 透视相机和盒体

```ts
// src/gl/cards.ts
const camera = new THREE.PerspectiveCamera(
  THREE.MathUtils.radToDeg(SCENE.fovY),
  SCENE.stageW / SCENE.stageH,
  SCENE.near,
  SCENE.far,
);
camera.position.set(0, 0, SCENE.cameraZ);
```

`fovY` 是 0.523599 弧度，即 30°。相机在 `z = 6`，所以在 `z = 0` 那个平面上，画面半高对应的世界长度是 `6 × tan(15°) = 1.607695`，这就是 `SCENE.halfHeightAtOrigin`。舞台高 720 像素，由此得到 `PPU = 720 / 2 / 1.607695 ≈ 223.9` 像素每世界单位（`src/core/layout.ts`）。

一张卡片是 `BoxGeometry(1, 0.6, 0.06)`，由 `cardHalfW / cardHalfH / cardHalfD` 乘 2 得到。相邻卡片中心相距 `cardSpacing = 1.07`，所以卡片之间有 0.07 的缝（没缩放时）。

`createCardGeometry` 还把盒体重排成和原作一致的面顺序和绕向。这很重要，因为这一遍绘制关闭了深度测试，面和面之间谁盖住谁，只由绘制顺序决定。细节见该函数的注释。

## 核心：选中程度是一个连续值

```ts
// src/core/layout.ts
export function focus(index: number, selectedF: number): number {
  return Math.max(0, 1 - Math.abs(selectedF - index));
}
```

`selectedF` 是缓动后的选中位置，它不是整数（详见 [05 导航](05-navigation.md)）。`focus` 是三角形函数：卡片正好在选中位置时为 1，离开一格时降到 0。

例：用户刚从第 0 张按右键到第 1 张，`selectedF` 缓动到 0.4。此时第 0 张 `focus = 0.6`，第 1 张 `focus = 0.4`，其余为 0。两张卡片各自处在"半选中"状态，都在放大，所以动画没有突变。

`cardDraws` 用同一个 `f` 同时驱动好几个量：

| 量        | 公式                                             | `f = 0` 时 | `f = 1` 时 |
| --------- | ------------------------------------------------ | ---------- | ---------- |
| 缩放      | `scaleBase + scaleFocus × f` = `0.86 + 0.16 × f` | 0.86       | 1.02       |
| 前移（z） | `zFocus × f` = `0.25 × f`                        | 0          | 0.25       |
| 描边强度  | `f × rowDim`，进着色器的 `uParams.x`             | 0          | 1          |

上面 `selectedF = 0.4` 的例子里，第 0 张缩放是 `0.86 + 0.16 × 0.6 = 0.956`，前移 `0.25 × 0.6 = 0.15`。

焦点在 Inputs 行时 `rowDim` 是 `SCENE.rowDimCard`（0.45），其余时候是 1。选中卡片仍然保持放大和前移（`f` 没变），只是描边和提亮降到 45%。

## 模型矩阵：一张卡片是怎么摆到位的

```ts
// src/gl/cards.ts
// T(x, cardY, z) · RotY(-x · rotYPerX) · Scale(s, s, 1)
let model = new THREE.Matrix4()
  .makeTranslation(x, SCENE.cardY, z)
  .multiply(new THREE.Matrix4().makeRotationY(-x * SCENE.rotYPerX))
  .multiply(new THREE.Matrix4().makeScale(scale, scale, 1));
```

矩阵作用在顶点上时从右往左读：先缩放，再绕竖轴旋转，最后平移。

走一遍。第 0 张卡片被选中，滚动位置为 0：

- `x = cardX(0, 0) = -1.98`，`f = 1`，缩放 1.02，`z = 0.25`。
- 旋转角 `-x × rotYPerX = 1.98 × 0.11 = 0.2178` 弧度，约 12.5°。左边的卡片角度为正，右边为负，所以两侧都朝中间偏。
- 取前表面右上角的本地坐标 `(0.5, 0.3, 0.03)`。缩放后是 `(0.51, 0.306, 0.03)`。
- 旋转：`x' = 0.51 × cos(0.2178) + 0.03 × sin(0.2178) ≈ 0.5044`，`z' = -0.51 × sin(0.2178) + 0.03 × cos(0.2178) ≈ -0.0809`，`y` 不变。
- 平移：世界坐标是 `(-1.98 + 0.5044, -0.49 + 0.306, 0.25 - 0.0809) = (-1.4756, -0.184, 0.1691)`。
- 投影到舞台：该点离相机 `6 - 0.1691`，近大远小系数 `6 / 5.8309 ≈ 1.029`，舞台 x 为 `640 + (-1.4756) × 223.9 × 1.029 ≈ 300`，舞台 y 为 `360 - (-0.184) × 223.9 × 1.029 ≈ 402`。

最后的 MVP 矩阵是 `viewProj × model`，`cardDraws` 里一次乘好，作为 uniform `uMvp` 传给顶点着色器。着色器另外还要 `uModel`，用来把法线转到世界空间。

## 倒角、高光扫动和描边

以下都在 `card.frag.glsl`，只作用于前表面。

**取图。** `printUv = uv * 0.62 + 0.2`：卡片表面只显示印花中间的 62%，范围是 0.2 到 0.82。

**倒角。**

```glsl
float edge = min(min(uv.x, (1.0 - uv.x)), min(uv.y, (1.0 - uv.y)));
float bevel = smoothstep(0.0, 0.035, edge);
col = mix(vec3(0.05, 0.05, 0.06), pr, bevel);
```

`edge` 是这个像素到表面四条边中最近一条的距离（uv 空间）。靠近边缘时 `bevel` 趋近 0，颜色混向深灰 `(0.05, 0.05, 0.06)`，形成一圈窄边。对选中卡片（宽约 238 像素，高约 143 像素），宽 0.035 的倒角在横向约 8 像素，纵向约 5 像素。

**高光扫动。**

```glsl
float s = ((uv.x * 0.8) + ((1.0 - uv.y) * 0.6));
float gloss = ((exp(-(pow(abs((s - (sweep - 0.4)) * 6.0), 2.0))) * 0.55) + (smoothstep(0.55, 1.1, s) * 0.1));
```

`s` 是沿斜向的位置，左下是 0，右上是 1.4。`exp(-(x * 6)^2)` 是钟形曲线，中心在 `s = sweep - 0.4`，宽度约 0.17。`sweep` 从 0 增长到 `sweepMax = 2.2`，增长速度 `sweepSpeed = 2.4` 每秒，所以 `2.2 / 2.4 ≈ 0.92` 秒走完。中心在 `s` 的 0 到 1.4 之间时才能看到，也就是 `sweep` 从 0.4 到 1.8 的期间。

只有 `f > 0.5` 的卡片才吃到 `s.sweep`，其余传 `sweepMax`，此时中心在 `s = 1.8`，超出卡片，高光为 0。选中新卡片（`selectApp`）或按 Enter、点击已选卡片都把 `s.sweep` 置 0，就重新扫一次。

`smoothstep(0.55, 1.1, s) * 0.1` 是一层常驻的右上角微亮。`pow` 外的 `abs` 和背景着色器里是同一个原因：负底数的 `pow` 在 GLSL 里未定义。

**光照。** 光方向写死在着色器里：

```glsl
vec3 L = vec3(-0.39801487, 0.696526, 0.5970223);
```

它指向左上前方，长度为 1。漫反射是 `max(dot(n, L), 0)`，前表面的颜色乘 `0.75 + 0.35 * diff`。因为卡片会旋转，法线跟着变，各卡片亮度不同。滚动位置为 0 时：第 0 张法线约 `(0.216, 0, 0.976)`，`diff ≈ 0.497`，系数 0.924；第 4 张（`x = 2.3`，角度 -0.253）法线约 `(-0.250, 0, 0.968)`，`diff ≈ 0.678`，系数 0.987。右边的卡片更亮一点。另有一项镜面高光 `pow(max(dot(n, H), 0), 40) * 0.15`。

**描边。**

```glsl
float rim = ((1.0 - smoothstep(0.0, 0.06, edge)) * sel);
col = mix(col, uGlow.xyz, (rim * 0.8));
```

`sel` 就是前面的 `f × rowDim`。选中程度越高，边缘 0.06 范围内越多地混入应用的光晕色 `uGlow`。再往后 `col * (0.9 + 0.25 * sel)` 让选中卡片整体提亮。侧面则走 `else` 分支：深灰色加一点光晕色。

## 倒影：把卡片倒过来再画一次

```ts
// src/gl/cards.ts
const floorY = SCENE.cardY - scale * SCENE.cardHalfH - SCENE.floorGap;
// T(0, 2 · floorY, 0) · RotX(π) · model
```

`floorY` 是卡片底边再往下 `floorGap = 0.02` 的高度，是那条"地面线"。倒影矩阵是在 `model` 外面再套一层：先绕 x 轴转 π（上下颠倒，同时前后也翻过来），再沿 y 平移 `2 × floorY`。

验证一下：选中卡片 `scale = 1.02`，`floorY = -0.49 - 1.02 × 0.3 - 0.02 = -0.816`。卡片中心原来在 `y = -0.49`，翻转后是 `-(-0.49) = 0.49`，再加 `2 × (-0.816) = -1.632`，得 `-1.142`。中心到地面线的距离，上方是 `-0.49 - (-0.816) = 0.326`，下方是 `-0.816 - (-1.142) = 0.326`，两边相等，所以是以地面线为轴的镜像。

翻转后看到的是盒体的背面，所以着色器在 `refl > 0.5` 时选 `vLocal.z` 为 -0.03 的那个面当"前表面"，并且 `uv.x = 1 - uv.x`，把图像再左右翻回来。

倒影的淡出：

```glsl
float below = clamp(((floorY - vWorldY) / height), 0.0, 1.0);
alpha = (0.32 * pow((1.0 - below), 2.2));
col = (col * 0.75);
```

`height` 是 `uGlow.w`，即 `scale × glowHeightK` = `scale × 0.6`，刚好是卡片的高度。`below` 从倒影顶部的约 0 渐变到底部的 1。`alpha` 在顶部最强，是 0.32；`below = 0.5` 时 `0.32 × 0.5^2.2 ≈ 0.07`；底部是 0。因为指数 2.2，淡出很快，前半段就衰减掉大部分。颜色再整体乘 0.75。

## 混合与绘制顺序

**预乘 alpha。** 普通的透明混合是 `结果 = 源色 × α + 背景 × (1 - α)`。预乘的意思是着色器输出时已经把颜色乘过了 α：

```glsl
fragColor = vec4((col * alpha), alpha);
```

混合方式设成源因子 One、目标因子 OneMinusSrcAlpha（`setPremultipliedBlending`），即 `结果 = 输出色 + 背景 × (1 - α)`。数值例：背景 0.2，源色 0.6，`α = 0.3`。普通混合：`0.6 × 0.3 + 0.2 × 0.7 = 0.32`。预乘：输出 `0.6 × 0.3 = 0.18`，`0.18 + 0.2 × 0.7 = 0.32`。结果相同，只是乘法挪到了着色器里。本体 `alpha = 1`，所以不透明；倒影的 `alpha` 随位置变。[04 颗粒](04-grain.md) 用的是同一种混合。

**绘制顺序。** 卡片这一遍不开深度测试（`depthTest: false`），哪张在前完全取决于后画的盖住先画的。`cardDraws` 的规则：

1. 先画全部倒影，再画全部本体，这样本体永远盖在倒影上。
2. 每一批里，按到 `selectedF` 的距离从远到近排序（`cardOrder`），选中的最后画，在最上层。
3. 中心 `|x| >= 3.4`（`cullX`）的卡片跳过。滚动位置为 0 时，十张卡片的 x 是 -1.98、-0.91、0.16、1.23、2.30、3.37、4.44……，所以前六张会画。不过第六张（3.37）的左边缘在 `3.37 - 0.43 = 2.94`，而舞台半宽只有 `640 / 223.9 ≈ 2.86` 个世界单位，它其实还在画面之外；一滚动，它就会滑进来。

一次 `renderer.render` 画一张卡片（`CardsPass.render`），每次先写入这张卡片自己的 `uMvp`、`uModel`、`uGlow`、`uParams`、`uTex`。
